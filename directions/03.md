# 🌈 03. Element Text Interactive

<p style="color:#6ee7b7;"><strong>Goal:</strong> Start turning the hand controls into an interactive experience. The right hand switch changes the element word, and the left hand distance scales the word from tiny to almost full-screen.</p>

<details open>
<summary><strong>🗺️ Big Picture</strong></summary>

In the last step, we created two useful controls:

1. The left hand gives us a normalized distance value from `0` to `1`.
2. The right hand gives us a switch that flips when the hand rotation crosses the threshold.

Now we can use those controls to affect something on screen:

1. Move the interactive state into a new file called `interactive.js`.
2. Store the four element names: `EARTH`, `WIND`, `FIRE`, and `WATER`.
3. Use the right hand switch to move through the element names.
4. Use the left hand distance to scale the text.
5. Draw the current element as huge centered text.

</details>

---

<details>
<summary><strong>📄 <span style="color:#60a5fa;">Step 1: Create <code>interactive.js</code></span></strong></summary>

Create a new file named `interactive.js`.

This file will hold the interactive part of the project. The hand tracking can stay in `sketch.js`, and the element/state logic can live in `interactive.js`.

<p style="color:#fbbf24;"><strong>💡 Why split files?</strong> As projects grow, one file can get crowded. Moving the interaction logic into its own file makes the project easier to read.</p>

</details>

<details>
<summary><strong>🔌 <span style="color:#34d399;">Step 2: Import <code>interactive.js</code></span></strong></summary>

In `index.html`, load `interactive.js` before `sketch.js`:

```html
<script src="interactive.js"></script>
<script src="sketch.js"></script>
```

The order matters because `sketch.js` will call functions that are defined in `interactive.js`.

</details>

<details>
<summary><strong>🌍 <span style="color:#f472b6;">Step 3: Store The Element Names</span></strong></summary>

In `interactive.js`, create an array:

```js
let elements = ["EARTH", "WIND", "FIRE", "WATER"];
```

An array lets us keep a list of related values in one place.

We also need to remember which element is currently selected:

```js
let currentElementIndex = 0;
```

Because arrays start counting at `0`, this starts on `"EARTH"`.

</details>

<details>
<summary><strong>📏 <span style="color:#facc15;">Step 4: Store The Text Scale Settings</span></strong></summary>

Add these variables in `interactive.js`:

```js
let elementScaleAmount = 0.5;
let minElementTextSize = 12;
let maxElementTextSize = 360;
```

These control how big the word gets:

- `elementScaleAmount` stores the current `0-1` scale value.
- `minElementTextSize` is the tiny size when the left hand value is close to `0`.
- `maxElementTextSize` is the huge size when the left hand value is close to `1`.

<p style="color:#86efac;"><strong>🎯 Interaction idea:</strong> The left hand distance becomes a scale control for the element word.</p>

</details>

<details>
<summary><strong>🔁 <span style="color:#38bdf8;">Step 5: Advance To The Next Element</span></strong></summary>

Create a helper function:

```js
function advanceElement() {
  currentElementIndex++;

  if (currentElementIndex >= elements.length) {
    currentElementIndex = 0;
  }
}
```

This moves to the next element in the array.

When the index gets past the end of the array, it goes back to `0`, so the cycle repeats:

```txt
EARTH -> WIND -> FIRE -> WATER -> EARTH
```

</details>

<details>
<summary><strong>📝 <span style="color:#a78bfa;">Step 6: Get The Current Element</span></strong></summary>

Create a helper function:

```js
function getCurrentElement() {
  return elements[currentElementIndex];
}
```

This gives us the word we should draw on screen right now.

</details>

<details>
<summary><strong>🖐️ <span style="color:#22c55e;">Step 7: Update The Scale With The Left Hand</span></strong></summary>

Create a helper function:

```js
function updateElementScale(scaleAmount) {
  if (scaleAmount === null) {
    return;
  }

  elementScaleAmount = scaleAmount;
}
```

The left hand distance already gives us a normalized value from `0` to `1`.

This helper stores that value in `elementScaleAmount`.

The `null` check means that if the left hand is not detected, the text keeps its last size instead of snapping.

</details>

<details>
<summary><strong>🔠 <span style="color:#c084fc;">Step 8: Draw Big Centered Text</span></strong></summary>

Create a drawing helper:

```js
function drawCurrentElement() {
  let elementTextSize = lerp(minElementTextSize, maxElementTextSize, elementScaleAmount);

  textAlign(CENTER, CENTER);
  textStyle(BOLD);
  textSize(elementTextSize);
  fill(255);
  stroke(0);
  strokeWeight(8);
  text(getCurrentElement(), width / 2, height / 2);
  textAlign(LEFT, BASELINE);
  textStyle(NORMAL);
}
```

This draws the current element word:

- centered horizontally
- centered vertically
- tiny when `elementScaleAmount` is close to `0`
- huge when `elementScaleAmount` is close to `1`
- bold
- white with a black outline

This line maps the `0-1` value to an actual text size:

```js
let elementTextSize = lerp(minElementTextSize, maxElementTextSize, elementScaleAmount);
```

`lerp()` means linear interpolation. It gives us a number between the minimum size and the maximum size.

The last two lines reset the text settings so the smaller hand labels still draw normally on the next frame.

</details>

<details>
<summary><strong>🔘 <span style="color:#fb923c;">Step 9: Connect The Right Hand Switch</span></strong></summary>

In `sketch.js`, find the `updateRightHandSwitch(rotationDegrees)` helper near the bottom of the file.

Inside that helper, find this `if` statement:

```js
if (isOverThreshold && rightHandWasOverThreshold === false) {
  rightHandSwitch = !rightHandSwitch;
}
```

Add `advanceElement()` inside that same `if` block, right after `rightHandSwitch = !rightHandSwitch;`:

```js
function updateRightHandSwitch(rotationDegrees) {
  let isOverThreshold = rotationDegrees > rightHandSwitchThreshold;

  if (isOverThreshold && rightHandWasOverThreshold === false) {
    rightHandSwitch = !rightHandSwitch;

    // new code ⬇️
    advanceElement();
    // new code ⬆️
  }

  rightHandWasOverThreshold = isOverThreshold;
}
```

`advanceElement()` comes from `interactive.js`, so make sure Step 2 is done first and `interactive.js` loads before `sketch.js`.

This means the element changes only once per switch gesture.

It does not keep changing while your hand stays over the threshold.

</details>

<details>
<summary><strong>🖼️ <span style="color:#2dd4bf;">Step 10: Update And Draw The Element Each Frame</span></strong></summary>

At the end of `draw()` in `sketch.js`, call:

```js
updateElementScale(leftHandDistanceNormalized);
drawCurrentElement();
```

`updateElementScale(leftHandDistanceNormalized)` sends the left hand distance value into `interactive.js`.

`drawCurrentElement()` draws the word.

Putting both near the end makes the word draw on top of the video and hand tracking graphics.

</details>

<details>
<summary><strong>✅ <span style="color:#6ee7b7;">Complete <code>interactive.js</code></span></strong></summary>

Your finished `interactive.js` should look like this:

```js
let elements = ["EARTH", "WIND", "FIRE", "WATER"];
let currentElementIndex = 0;
let elementScaleAmount = 0.5;
let minElementTextSize = 12;
let maxElementTextSize = 360;

function advanceElement() {
  currentElementIndex++;

  if (currentElementIndex >= elements.length) {
    currentElementIndex = 0;
  }
}

function getCurrentElement() {
  return elements[currentElementIndex];
}

function updateElementScale(scaleAmount) {
  if (scaleAmount === null) {
    return;
  }

  elementScaleAmount = scaleAmount;
}

function drawCurrentElement() {
  let elementTextSize = lerp(minElementTextSize, maxElementTextSize, elementScaleAmount);

  textAlign(CENTER, CENTER);
  textStyle(BOLD);
  textSize(elementTextSize);
  fill(255);
  stroke(0);
  strokeWeight(8);
  text(getCurrentElement(), width / 2, height / 2);
  textAlign(LEFT, BASELINE);
  textStyle(NORMAL);
}
```

</details>

<details>
<summary><strong>🧩 <span style="color:#f0abfc;">What The Interactive File Is Doing</span></strong></summary>

The new file has four jobs:

1. Store the possible element words.
2. Remember which element is selected.
3. Store the current left-hand scale value.
4. Draw the selected element on the canvas.

The hand tracking still happens in `sketch.js`.

The interactive state happens in `interactive.js`.

<p style="color:#86efac;"><strong>🎯 Result:</strong> The right hand switch controls which word is shown, and the left hand distance controls how large the word gets.</p>

</details>
