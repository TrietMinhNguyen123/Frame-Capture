# 👐 01. HandPose Keypoints Project

<p style="color:#6ee7b7;"><strong>Goal:</strong> Build a simple ml5.js HandPose sketch that opens the webcam, finds hands, and draws green dots on each detected hand keypoint.</p>

<details open>
<summary><strong>🗺️ Big Picture</strong></summary>

By the end of this project, your browser will show your webcam video on a centered canvas. When you hold up your hand, ml5's HandPose model will find important points on your hand and p5.js will draw green circles on them.

The project has five main parts:

1. Load p5.js so we can draw on a canvas.
2. Load ml5.js so we can use the HandPose machine learning model.
3. Open the webcam.
4. Ask HandPose to detect hands in the webcam video.
5. Draw the video and draw green circles on the hand keypoints.

</details>

<details>
<summary><strong>🔌 <span style="color:#34d399;">Step 3: Import p5.js, ml5.js, And Your Sketch</span></strong></summary>

At the bottom of the `<body>`, add these three script tags:

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.3/p5.min.js"></script>
<script src="https://unpkg.com/ml5@1/dist/ml5.min.js"></script>
<script src="sketch.js"></script>
```

The order matters:

- `p5.js` loads first because functions like `createCanvas()`, `createCapture()`, `image()`, and `circle()` come from p5.
- `ml5.js` loads second because the HandPose model comes from ml5.
- `sketch.js` loads last because it uses both p5 and ml5.

<p style="color:#f87171;"><strong>🚨 Common bug:</strong> If <code>sketch.js</code> loads before p5 or ml5, the browser may not know what those functions are yet, and the page can look blank.</p>

</details>

<details>
<summary><strong>📄 <span style="color:#38bdf8;">Step 4: Create Your JavaScript File</span></strong></summary>

Create a file named `sketch.js`.

At the top of the file, create variables for the HandPose model, the webcam video, and the detected hands:

```js
let handPose;
let video;
let hands = [];
```

Here is what each variable stores:

- `handPose` will hold the ml5 HandPose model.
- `video` will hold the webcam feed.
- `hands` will hold the detection results from the model.

<p style="color:#fbbf24;"><strong>💡 Array idea:</strong> The <code>hands</code> variable starts as an empty array because at the beginning of the sketch, no hands have been detected yet.</p>

</details>

<details>
<summary><strong>📐 <span style="color:#fb7185;">Step 5: Choose The Canvas Size</span></strong></summary>

Create two variables for the canvas size:

```js
let canvasWidth = 960;
let canvasHeight = 720;
```

This makes the canvas larger than the default webcam example. The size `960 x 720` keeps a `4:3` ratio, which matches the common webcam ratio of `640 x 480`.

<p style="color:#6ee7b7;"><strong>✅ Nice detail:</strong> Keeping the canvas and video in the same ratio helps the video avoid looking stretched.</p>

</details>

<details>
<summary><strong>🧠 <span style="color:#c084fc;">Step 6: Load The HandPose Model</span></strong></summary>

p5 has a special function called `preload()`. Code inside `preload()` runs before `setup()`.

Use `preload()` to load the HandPose model:

```js
function preload() {
    handPose = ml5.handPose();
}
```

This line:

```js
handPose = ml5.handPose();
```

asks ml5 to create a HandPose model and stores it in the `handPose` variable.

<p style="color:#fbbf24;"><strong>💡 Why preload?</strong> We use <code>preload()</code> because we want the model to be ready before the sketch starts setting up the canvas and webcam.</p>

</details>

<details>
<summary><strong>📷 <span style="color:#22c55e;">Step 7: Set Up The Canvas And Webcam</span></strong></summary>

Next, create the `setup()` function:

```js
function setup() {
    createCanvas(canvasWidth, canvasHeight);

    video = createCapture(VIDEO, { flipped: true });
    video.size(canvasWidth, canvasHeight);
    video.hide();

    handPose.detectStart(video, gotHands);
}
```

This function runs once when the sketch starts.

This line creates the drawing area:

```js
createCanvas(canvasWidth, canvasHeight);
```

Because `canvasWidth` is `960` and `canvasHeight` is `720`, the canvas becomes `960 x 720`.

This line asks the browser for the webcam and flips it like a mirror:

```js
video = createCapture(VIDEO, { flipped: true });
```

The word `VIDEO` tells p5 that we want video input from the camera. The `{ flipped: true }` part mirrors the video horizontally, so moving your right hand on screen feels like looking in a mirror.

This line resizes the webcam feed:

```js
video.size(canvasWidth, canvasHeight);
```

The video is resized to match the canvas, so the video and the drawing area line up.

This line hides the raw HTML video element:

```js
video.hide();
```

We hide it because we do not want the browser to show a separate video element under the canvas. Instead, we will draw the webcam image directly onto the p5 canvas.

</details>

<details>
<summary><strong>🟢 <span style="color:#4ade80;">Step 8: Start Detecting Hands</span></strong></summary>

Still inside `setup()`, this line starts the HandPose detection:

```js
handPose.detectStart(video, gotHands);
```

This tells HandPose:

- use `video` as the input
- run the function `gotHands` whenever results are ready

The function `gotHands` is called a callback function. A callback is a function that gets called later, after another process finishes some work.

<p style="color:#93c5fd;"><strong>🔄 What's happening:</strong> HandPose is constantly checking the webcam. Whenever it finds hand data, it sends the results into <code>gotHands</code>.</p>

</details>

<details>
<summary><strong>📦 <span style="color:#facc15;">Step 9: Save The Hand Detection Results</span></strong></summary>

Create the callback function:

```js
function gotHands(results) {
    hands = results;
}
```

The `results` variable contains whatever HandPose detected in the current video frame.

Then this line saves those results:

```js
hands = results;
```

The results are stored in the global `hands` array so the `draw()` function can use them.

Each item inside `hands` is one detected hand. Each hand has a `keypoints` array. The `keypoints` array contains points like the wrist, finger joints, and fingertips.

</details>

<details>
<summary><strong>🖼️ <span style="color:#2dd4bf;">Step 10: Draw The Webcam Video</span></strong></summary>

Now create the `draw()` function:

```js
function draw() {
    background(0);
    image(video, 0, 0, width, height);
}
```

The `draw()` function runs over and over again, many times per second.

This line clears the canvas with black:

```js
background(0);
```

In p5, `0` means black.

This line draws the webcam image onto the canvas:

```js
image(video, 0, 0, width, height);
```

The first value, `video`, is the image we want to draw.

The next two values, `0, 0`, are the x and y position. This places the video at the top-left corner of the canvas.

The last two values, `width, height`, make the video fill the canvas.

</details>

<details>
<summary><strong>🔁 <span style="color:#818cf8;">Step 11: Loop Through The Detected Hands</span></strong></summary>

Inside `draw()`, after drawing the video, loop through the `hands` array:

```js
function draw() {
    background(0);
    image(video, 0, 0, width, height);

    // new code ⬇️
    for (let i = 0; i < hands.length; i++) {
        let hand = hands[i];
    }
    // new code ⬆️
}
```

This loop checks every hand that was detected.

The variable `i` is the index number of the current hand. If one hand is detected, the loop runs once. If two hands are detected, the loop runs twice.

This line gets the current hand:

```js
let hand = hands[i];
```

Now we can look inside that hand and find its keypoints.

</details>

<details>
<summary><strong>📍 <span style="color:#fb923c;">Step 12: Loop Through The Hand Keypoints</span></strong></summary>

Inside the hand loop, add a second loop:

```js
function draw() {
    background(0);
    image(video, 0, 0, width, height);

    for (let i = 0; i < hands.length; i++) {
        let hand = hands[i];

        // new code ⬇️
        for (let j = 0; j < hand.keypoints.length; j++) {
            let keypoint = hand.keypoints[j];
        }
        // new code ⬆️
    }
}
```

This loop goes through every keypoint on the current hand.

The variable `j` is the index number of the current keypoint.

This line gets the current keypoint:

```js
let keypoint = hand.keypoints[j];
```

Each `keypoint` has an `x` position and a `y` position. Those positions tell us where that part of the hand is on the canvas.

</details>

<details>
<summary><strong>🟩 <span style="color:#86efac;">Step 13: Draw Green Dots On The Keypoints</span></strong></summary>

Inside the keypoint loop, draw a circle:

```js
function draw() {
    background(0);
    image(video, 0, 0, width, height);

    for (let i = 0; i < hands.length; i++) {
        let hand = hands[i];

        for (let j = 0; j < hand.keypoints.length; j++) {
            let keypoint = hand.keypoints[j];

            // new code ⬇️
            fill(0, 255, 0);
            noStroke();
            circle(width - keypoint.x, keypoint.y, 12);
            // new code ⬆️
        }
    }
}
```

This line sets the drawing color to green:

```js
fill(0, 255, 0);
```

The three numbers are RGB values:

- `0` red
- `255` green
- `0` blue

This line removes the outline around the circle:

```js
noStroke();
```

This line draws the dot:

```js
circle(width - keypoint.x, keypoint.y, 12);
```

The circle is placed at the keypoint position. The number `12` is the size of the circle.

<p style="color:#fbbf24;"><strong>💡 Mirror fix:</strong> Because the camera video is flipped, the keypoint's x position also needs to be flipped. <code>width - keypoint.x</code> mirrors the dot across the canvas so it lines up with your hand.</p>

</details>

<details>
<summary><strong>✅ <span style="color:#6ee7b7;">Complete <code>sketch.js</code></span></strong></summary>

Your finished `sketch.js` should look like this:

```js
let handPose;
let video;
let hands = [];

let canvasWidth = 960;
let canvasHeight = 720;

function preload() {
    handPose = ml5.handPose();
}

function setup() {
    createCanvas(canvasWidth, canvasHeight);

    video = createCapture(VIDEO, { flipped: true });
    video.size(canvasWidth, canvasHeight);
    video.hide();

    handPose.detectStart(video, gotHands);
}

function gotHands(results) {
    hands = results;
}

function draw() {
    background(0);
    image(video, 0, 0, width, height);

    for (let i = 0; i < hands.length; i++) {
        let hand = hands[i];

        for (let j = 0; j < hand.keypoints.length; j++) {
            let keypoint = hand.keypoints[j];

            fill(0, 255, 0);
            noStroke();
            circle(width - keypoint.x, keypoint.y, 12);
        }
    }
}
```

</details>

<details>
<summary><strong>🧩 <span style="color:#f0abfc;">What The Nested Loops Are Doing</span></strong></summary>

There are two loops because the data has two levels:

```js
for (let i = 0; i < hands.length; i++) {
```

This first loop goes through every detected hand.

```js
for (let j = 0; j < hand.keypoints.length; j++) {
```

This second loop goes through every keypoint on the current hand.

So the sketch is saying:

1. Look at each detected hand.
2. For that hand, look at each keypoint.
3. Draw a green dot at that keypoint's location.

<p style="color:#86efac;"><strong>🎯 Result:</strong> Green dots appear on different parts of your hand.</p>

</details>
